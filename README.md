# Astro UXDS Nova — Issues

This repository is the **public issue tracker** for the [Astro UXDS Nova](https://www.astrouxds.com/) design system npm packages. Source code is maintained in a private repository; this repo exists so anyone using the published packages can report bugs or request features without needing access to the private source.

## Before opening an issue

- Search [existing issues](../../issues) to see if it's already been reported.
- Include the exact package name and version (`npm ls @rocketcommunicationsinc/astrouxds-nova-react` or check your `package.json`).
- Include a minimal reproduction where possible (code snippet, CodeSandbox/StackBlitz link, etc.).

## Contributing code

This repo does not host source code and does not accept pull requests. Source lives in a private repository; mention in your issue if you'd like to discuss contributing and we'll follow up.
